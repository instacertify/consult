How it works

  1. Each landing is stored as its own HTML and public URL
  2. Backend lists every landing with its full URL and Open / Edit actions
  3. Edit that page’s URL path and words without touching the other landings
  4. Optional directory at / only links to the independent pages — it does not merge their content

Example URLs: /bis-certification, /lmpc-certificate, /msds-certificate — each fully editable in admin.
